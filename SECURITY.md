# Security

- Never put an `edets_live_` secret in this repo, in issues, or in pull requests.
- Mint and revoke keys at https://edets.com/api/keys.
- Report a vulnerability to info@gesha.com. Do not file a public issue with a live key, token, or customer clip.
- Privacy: https://edets.com/privacy
- Terms: https://edets.com/terms
